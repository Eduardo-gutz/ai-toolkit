# Conventions: generate `.context/conventions.md`

You are an AI agent. Your job is to generate **a single file** in the
target repo: `.context/conventions.md`.

> **This file is OPTIONAL.** If the project has no non-obvious contracts
> (response format, auth headers, pagination, etc.), the conductor may
> skip this step. If you are invoked with a discovery JSON that has no
> cross-cutting concerns, return a minimal output that says
> "Not applicable — no non-obvious contracts were detected".

## Inputs

- Target repo: path of the repo to analyze.
- Discovery JSON: the complete JSON produced by `02-discovery.md`. You
  especially need `cross_cutting`.

## Output

**A single file**: `<repo>/.context/conventions.md`.

If it already exists, **ask the user** before overwriting (proposed
diff section by section).

## Absolute rules

- Do not invent: if you did not find a contract in the code, declare it
  as "pending" or "not found".
- Do not copy conventions from other projects. Analyze ONLY this repo.
- Do not add emojis.
- Cite real paths with `path/to/file:line`.
- Snippets must be **real** from the repo (copied or simplified from
  the cited original), not invented.

If a section does not apply to the project, omit it or put "not found".

## How to derive each section

- **Response format / errors**: read 3-5 endpoints from the sample and
  look at the JSON shape. If they all follow the same envelope,
  document it. If it varies, mark it as "not standardized" and show the
  variants.
- **Mandatory headers**: look at the middleware files. List the headers
  that are always set (`X-Request-Id`, `Content-Type`) and the ones
  always validated (`Authorization`, `Accept-Language`).
- **Authentication**: look at the auth middleware. Read how it extracts
  the token, how it validates it, and how it exposes the user to the
  rest. Cite the file.
- **Pagination**: look at list endpoints. Look at query params and the
  response shape.
- **Frontend**: if `samples.ui_component` is not `null`, read 2-3
  components. If there is no UI, omit the entire section.
- **i18n, jobs, logging, errors, feature flags, caching**: use
  `cross_cutting` from the discovery JSON to know which apply. For
  each that applies, find the setup file (logger config, i18n init,
  error middleware) and copy a snippet.

## If the discovery JSON has empty or "unknown" fields

Do not invent. If `cross_cutting.auth` is `"none"`, omit
Authentication. If most sections do not apply, return a minimal
output: "Not applicable — no non-obvious contracts were detected".
