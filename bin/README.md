# bin/

CLI entry points. `bin/ai-toolkit.mjs` is the main command.

## Planned commands

```
ai-toolkit init [--tools=opencode,claude-code] [--profile=backend]
ai-toolkit sync [--tools=...] [--profile=...]
ai-toolkit add <agent|skill|mcp|rule> <name>
ai-toolkit remove <type> <name>
ai-toolkit list [--tools=...]
ai-toolkit validate
ai-toolkit doctor     # checks tool installation, env, version mismatches
```
